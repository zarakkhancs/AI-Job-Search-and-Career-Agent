# 3.1 Feature-to-Design Traceability

Every feature is reachable from the GUI. Features that are also available from the CLI additionally use the Command pattern (`CommandInvoker` and the matching `*Command` class, see SD-13); this is marked "Command (CLI)" in the last column. F06 has no CLI command because its alerts are produced by the scheduler and shown in the GUI.

| Feature | Description | Type | Related Use Case | Related Sequence Diagram | Primary Classes | Key Methods | Design Pattern(s) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **F01 - Resume Import & Parsing** | Extracts structured data such as skills and experience from a PDF. | Hybrid | UC-01 | SD-01 Import Resume | `ResumeController`, `IngestionService`, `ExtractionStrategy`, `PDFResumeExtractor`, `AIEngineFacade`, `ResumeParsePromptFactory`, `GeminiClient` | `uploadResume()`, `ingestResume()`, `extract()`, `parseResume()` | Strategy, Facade, Factory Method, Adapter, Command (CLI) |
| **F02 - Job Posting Ingestion** | Imports job requirements from a URL or pasted text. | Deterministic | UC-02 | SD-02 Import Job Posting | `JobController`, `IngestionService`, `ExtractionStrategy`, `WebJobScraper`, `PastedTextJobParser` | `importJob()`, `ingestJob()`, `selectStrategy()`, `extract()` | Strategy, Command (CLI) |
| **F03 - Skill Gap & Match Analysis** | Cross-references resume data against a job to identify missing skills. | AI | UC-03 | SD-03 Analyze Skill Gap and Match | `AIFeatureController`, `AIEngineFacade`, `MatchPromptFactory`, `MatchAnalysisPrompt`, `GeminiClient` | `analyzeMatch()`, `analyzeSkillGap()`, `createPrompt()`, `generate()` | Facade, Factory Method, Adapter, Command (CLI) |
| **F04 - Tailored Cover Letter** | Drafts a customized cover letter aligning with a job description. | AI | UC-04 | SD-04 Generate Cover Letter | `AIFeatureController`, `AIEngineFacade`, `CoverLetterPromptFactory`, `CoverLetterPrompt`, `GeminiClient` | `generateCoverLetter()`, `createPrompt()`, `generate()` | Facade, Factory Method, Adapter, Command (CLI) |
| **F05 - Pipeline State Management** | Moves an application between pipeline stages (e.g., Wishlist, Applied). | Deterministic | UC-05 | SD-05 Manage Application Pipeline | `ApplicationController`, `ApplicationService`, `JobApplication`, `ApplicationState`, all concrete states | `changeStage()`, `changeState()`, `handleTransition()` | State, Command (CLI) |

| **F07 - Interview Prep Sheet** | Generates 5 technical and 3 behavioral questions tailored to a job. | AI | UC-07 | SD-07 Generate Interview Prep Sheet | `AIFeatureController`, `AIEngineFacade`, `PrepSheetPromptFactory`, `InterviewPrompt`, `GeminiClient` | `generatePrepSheet()`, `createPrompt()`, `generate()` | Facade, Factory Method, Adapter, Command (CLI) |

| **F10 - Application Package Exporter** | Compiles the resume and cover letter into a downloadable document. | Deterministic | UC-10 | SD-10 Export Application Package | `ExportController`, `DocumentGenerator`, `ExportFile` | `exportPackage()`, `generatePDF()`, `generatePlainText()` | Command (CLI only) |
