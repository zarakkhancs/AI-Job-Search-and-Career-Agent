# UMLet diagrams

All Stage 1 diagrams as UMLet files (open with UMLet, File > Open).

| File | Diagram |
|---|---|
| `class_diagram_view_A_...uxf` to `class_diagram_view_D_...uxf` | Class diagram, Views A-D (stage1_class_diagram.md) |
| `use_case_diagram.uxf` | Use-case diagram (stage1_use_cases.md) |
| `sequence_SD-01_...uxf` to `sequence_SD-13_...uxf` | Sequence diagrams SD-01 to SD-13 (stage1_sequence_diagrams.md) |

Exported images go in `png/` (same file name as the `.uxf`, `.png` extension). Export from UMLet with File > Export as.
